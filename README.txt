HOW TO PLAY & OBJECTIVES
------------------------
Guide the character into the glowing portal in each of the 24 puzzle levels.
You can wear nested shells (up to 4 layers). Shedding an outer shell in mid-air
gives you an extra boost jump while leaving the empty shell behind to press
buttons, weigh down platforms, or reuse later.

CONTROLS
--------
- Move Left / Right : A / D  or  Left / Right Arrow Keys
- Jump              : W, Up Arrow, or Spacebar
- Shed Shell        : Press W, Up Arrow, or Spacebar again while in mid-air
- Restart Level     : R (or click the Restart button in the top bar)
- Toggle Hint       : H (shows solution path and unlocks the Skip button)
- Level Select      : Esc or B (or click the grid icon in the top bar)
- Mute / Unmute     : M (or click the speaker icon in the top bar)
- Mobile / Touch    : Use the on-screen D-Pad and Jump/Shed buttons

GAME MECHANICS
--------------
- Empty Shells      : Walk into a shell one size larger than you to wear it.
                      Empty shells fall harmlessly through spikes and can hold
                      down green floor buttons.
- Purple Blocks     : Fragile platforms that break if stepped on by a character
                      or shell larger than 1x1.
- Orbs (+ / -)      : Red (+) orbs grow you by one shell layer; Purple (-) orbs
                      shrink you by one layer (fatal if already at 1x1).
- Paint Gates       : Blue paint locks your shell (disables shedding and orbs);
                      Green/Red paint unlocks your shell again.
- Weight Meters     : Stand on or place shells on orange weight pads to match
                      the required weight and open numbered doors.
- Special Shells    : Gold-striped shells let any smaller size nest inside;
                      Gray explosive shells detonate on landing to break cracked walls.
